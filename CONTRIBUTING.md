# Contributing

- Work happens through GitHub issues and pull requests; every PR links its issue.
- Sign off every commit (Developer Certificate of Origin): `git commit -s`. Contributors keep their copyright.
- Code is Apache-2.0 (`LICENSE`); data is CC BY 4.0 (`data/LICENSE.md`).
- Public or synthetic source data only. Record every source document with its URL, retrieval date and SHA-256.
- Every reported number is regenerated by a committed script. Tests and CI (`make lint`, `make test`) must pass.
- Python 3.12.
